# 수어대화

농인과 청인이 각자 자기 아이폰을 들고 마주 앉아 대화하는 앱입니다.
청인 폰 카메라가 농인의 수어를 보고 한국어 문장으로 바꿔 보여 줍니다. 청인이 말한 내용은 농인 폰에 자막으로 뜹니다.
인터넷과 서버 없이 폰 두 대만으로 동작하며, 카메라 영상과 음성은 저장하거나 밖으로 보내지 않습니다.

실증적AI개발프로젝트(02분반) 캡스톤, 팀 **얼간이같은 금쪽이들**.
수어 인식 모델 학습 코드는 [Sign-Language-Translation](https://github.com/yvns2nvg/Sign-Language-Translation) 저장소에 있고, 이 저장소는 그 모델을 아이폰에서 돌리는 앱입니다.

## 어떻게 쓰나

1. 두 사람이 앱을 켜고 각자 역할(농인 / 청인)을 고릅니다.
2. 근처 사용자 목록에서 상대를 찾아 연결을 요청하고, 상대가 수락하면 대화가 시작됩니다.
3. 청인은 폰 뒷면 카메라로 농인의 상반신을 비춥니다. 농인이 수어를 하고 3초 정도 멈추면 청인 화면에 문장이 나옵니다.
4. 청인은 **누르고 말하기** 버튼을 누른 채로 말합니다. 버튼을 떼면 문장이 확정되어 농인 폰에 자막으로 갑니다.

무거운 계산(관절 추출, 수어 모델, 음성 인식)은 모두 청인 폰에서 합니다. 농인 폰은 자막만 보여 줍니다.

## 수어가 문장이 되기까지

```
카메라 30fps
 → MediaPipe Holistic       몸 13 + 손 21×2 + 얼굴 34 = 89개 점
 → One-Euro 필터, 정규화      떨림을 줄이고 어깨 기준으로 위치·크기를 맞춤
 → 구간 자르기                손이 움직이기 시작하면 녹화, 멈추면 한 단어로 끊음
 → 특징 만들기                64프레임 × 356차원
 → 분류 모델(ONNX)            1,200개 단어 중 하나
 → 문장 만들기                [진단서, 원하다] → "진단서를 원해요"
```

- 1순위 확률이 50% 미만이거나 동작이 0.7초보다 짧으면 단어로 받지 않습니다.
- 한국수어에는 조사와 어미가 거의 없어서, 모델 출력은 단어를 늘어놓은 형태입니다. 단어마다 품사, 명사 종류(사람·장소·사물·시간·탈것), 동사 종류를 표로 만들어 두고, 그 조합으로 조사와 어미를 붙입니다.
  예를 들어 사물 + 타동사이면 "을/를", 장소 + 이동 동사이면 "에"를 붙입니다.
  형태소 분석기(Kiwi)는 아이폰에서 쓸 수 없어서, PC에서 1,200개 단어의 결과를 미리 계산한 표(`sentence_tables.json`)를 앱에 넣었습니다.
- 자세한 설명은 [`docs/발표_수어인식_문장생성_구조.md`](docs/발표_수어인식_문장생성_구조.md)에 있습니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `SignTrans/` | iOS 앱 (SwiftUI). 화면, 카메라, 음성 인식, 기기 연결 |
| `SignCore/` | 인식 로직 Swift 패키지. 전처리, 구간 자르기, 문장 만들기, ONNX 모델 실행 |
| `Vendor/MediaPipe/` | MediaPipe iOS 바이너리를 Xcode 앱에서 쓰기 위한 로컬 래퍼 |
| `fixtures/` | Python 원본과 Swift 구현의 결과를 비교하는 테스트 데이터 |
| `tools/` | 모델 변환(PyTorch → ONNX), 테스트 데이터·문장 표 생성 스크립트 |
| `docs/` | 요구사항 문서(PRD), 구현 계획, 발표 자료 |

## 빌드

필요한 것: Mac, Xcode 26 이상, iOS 26 이상 아이폰, [XcodeGen](https://github.com/yonaskolb/XcodeGen).
유료 개발자 계정이 없어도 무료 계정으로 내 폰에 설치할 수 있습니다(설치 후 7일간 동작).

```bash
brew install xcodegen
xcodegen                     # project.yml → SignTrans.xcodeproj
open SignTrans.xcodeproj
```

`project.yml`의 `DEVELOPMENT_TEAM`을 본인 팀 ID로 바꾼 뒤 폰을 연결하고 실행하면 됩니다.
처음 설치하면 폰에서 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고, **설정 → 일반 → VPN 및 기기 관리**에서 개발자를 신뢰해야 합니다.

시뮬레이터에서는 카메라가 없어서 수어 인식은 확인할 수 없고, 화면과 연결 흐름만 볼 수 있습니다.

## 테스트

```bash
cd SignCore && swift test                    # 인식 로직 (Python 원본과 결과 비교)
xcodebuild test -project SignTrans.xcodeproj -scheme SignTrans \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'   # 앱 상태 관리
```

## 측정 결과

| 항목 | 결과 |
|---|---|
| Swift 전처리 vs Python 원본 | 오차 0.0001 미만, 실시간 410프레임 구간 판정 100% 일치 |
| ONNX 변환 모델 vs PyTorch | 1순위 단어 200/200 일치 |
| 문장 생성 vs Python 원본 | 평가 문장 130개, 무작위 조합 1,000개 모두 일치 |
| 단어 인식 정확도 (PC, 학습에 없던 수어사) | top-1 98.0% |
| 아이폰 14 Pro 카메라 처리 | 30fps 유지 |
| 아이폰 14 Pro 단어 1개 판정 시간 | 6~10ms (모델만 1.8ms) |

## 한계

- 학습 데이터는 스튜디오에서 찍은 영상이라, 실제 폰 카메라로 하면 확률이 많이 떨어집니다. 학습 영상의 수어 동작을 보고 그대로 따라 하면 잘 나옵니다.
- 1,200개 단어에 "먹다", "있다", "병원", "사랑하다" 같은 기본 단어가 빠져 있습니다.
- 문장 규칙은 단어 종류만 보기 때문에 "감기에 걸렸어요" 같은 관용 표현은 만들지 못합니다("감기예요"가 됩니다).
- 시연용으로 몇 개 단어만 보게 하는 모드가 있습니다(`SignTrans/App/DebugAutomation.swift`의 `-demoVocab`). 일반 모드보다 인식이 훨씬 안정적이지만, 정해 둔 단어 밖의 수어는 받지 않습니다.

## 데이터와 라이선스

- 수어 인식 모델은 AI Hub 「수어 영상」 데이터셋(한국지능정보사회진흥원)으로 학습했습니다. 원본 데이터는 이 저장소에 없습니다.
  데이터 이용은 AI Hub 약관을 따르며, 모델 파일(`sign_c1200.onnx`)은 학습 목적으로만 공개합니다.
- MediaPipe(`holistic_landmarker.task`)는 Google의 Apache 2.0 라이선스를 따릅니다.
